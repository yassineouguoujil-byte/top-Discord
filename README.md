# 📊 Discord Top

Discord Top est un site web qui présente les serveurs Discord les plus populaires et actifs du moment.

Il permet aux visiteurs de découvrir les plus grandes communautés de gaming, de création et de discussion en ligne.

---

## 🎯 Objectif

Le site a pour objectif de :

- Mettre en avant les serveurs Discord les plus connus  
- Présenter leur popularité grâce aux notes ⭐  
- Indiquer le nombre approximatif de membres  
- Donner une vue rapide des meilleures communautés  

---

## 🖥️ Fonctionnement

Le site est structuré en plusieurs sections :

### 🏠 Accueil

Affiche les serveurs principaux mis en avant.

### 🏆 Top 10

Présente les serveurs les plus populaires avec :

- Une note en étoiles ⭐  
- Une estimation du nombre de membres  

### 📖 À propos

Explique le rôle des serveurs Discord et leur évolution depuis la création de la plateforme.

### 📌 Contact

Permet de contacter le créateur du site.
